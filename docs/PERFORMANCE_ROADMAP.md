> **고객 배포용 자료** · v1.0 · 2026-04-29

> 정량적으로 제시하기 위한 자료입니다.

## Executive Summary

| 항목 | 시연 환경 (현재) | 도입 1단계 (GPU 1장) | 도입 2단계 (GPU 서버) |
|---|---|---|---|
| 응답 시간 (질의 1건) | 20–40초 | **3–5초** | **1–2초** |
| 동시 사용자 처리 | 1–2명 | 10–20명 | 50–100명 |
| 검색 정확도 (Top-5 Recall) | 87% | 90% | 92% |
| 답변 거절(할루시네이션 차단) | ✅ 동일 | ✅ 동일 | ✅ 동일 |
| 외부 데이터 유출 | **0건 (폐쇄망 보장)** | **0건** | **0건** |
| 추가 비용 (장비) | — | 약 300만원 | 3,000만원~ |

> **핵심 메시지** — 현재 시연의 응답 속도는 **데모용 최저 사양 결과**이며,
> 도입 시 GPU 1장 추가만으로 **상용 챗봇 수준 (3~5초)** 까지 즉시 향상됩니다.
> 보안·정확도·기능은 모든 단계에서 동일하게 보장됩니다.

## 1. 본 프로젝트 소개

### 1.1 한 줄 요약
**조직 내부 문서(법령·규정·계약서·매뉴얼 등)를 외부 인터넷 연결 없이 검색·요약·질의응답할 수 있는 폐쇄형 AI 시스템**

### 1.2 시장 차별점

| 항목 | ChatGPT / Copilot | 일반 SaaS RAG | **BAIKAL Private AI** |
|---|---|---|---|
| 데이터 위치 | 외부 클라우드 (미국) | 외부 서버 | **고객 내부 망** |
| 망분리 환경 | ❌ 사용 불가 | ❌ 사용 불가 | ✅ **사용 가능** |
| 학습 데이터화 위험 | 있음 (정책 변경 가능) | 계약 의존 | **물리적으로 0** |
| 출처 표시 | 부분적 | 부분적 | ✅ **모든 답변 강제** |
| 답변 거절 (모를 때) | 약함 (할루시네이션) | 약함 | ✅ **신뢰도 기반 자동 거절** |
| 한글 문서 형식 | PDF/DOCX 위주 | PDF/DOCX 위주 | ✅ **HWP/HWPX/HWPML 지원** |

### 1.3 적용 가능 영역
- **공공기관**: 법령·조례·예규 검색, 민원 응대 보조
- **금융**: 약관·내규·감독규정 질의응답
- **법무**: 판례·계약서 검토
- **제조/연구**: 기술문서·매뉴얼·특허 검색
- **의료**: 진료지침·임상연구 자료 (단, 진단 보조는 별도 검증 필요)

## 2. 현재 시연 환경의 한계 (정직한 공개)

### 2.1 시연 환경 사양

| 구분 | 사양 |
|---|---|
| CPU | Intel/AMD 데스크톱 8코어 |
| RAM | 16~32GB |
| GPU | **없음 (CPU 추론)** |
| 모델 | qwen2.5:7b, qwen2.5vl:7b, bge-m3 |
| 환경 | 노트북 1대 / Docker Compose |

### 2.2 측정된 성능

| 지표 | 측정값 | 비고 |
|---|---|---|
| 첫 질의 (cold start) | 50~60초 | 모델 메모리 로딩 1회만 발생 |
| 일반 질의 (warm) | 20~40초 | 답변 길이에 따라 변동 |
| 임베딩 1청크 | 0.5~1초 | 문서 1페이지당 약 5초 |
| 검색 Top-5 | < 0.3초 | pgvector HNSW 인덱스 |

### 2.3 왜 느린가 — 기술적 이유

LLM 추론은 GPU의 행렬 병렬 연산에 최적화되어 있습니다. CPU는 GPU 대비
약 **20~50배 느린 추론 속도**를 보이며, 이는 알고리즘이 아닌 **하드웨어
특성**입니다. 동일 모델·동일 코드를 GPU에서 실행하면 즉시 향상됩니다.

> 시연의 "느림"은 **보안 검증을 위한 최저 사양 시연**의 결과이며,
> 제품 자체의 한계가 아닙니다.

## 3. 단계별 성능 향상 로드맵

### 3.1 전체 흐름

```
[현재 시연]              [1단계 도입]            [2단계 확장]            [3단계 고도화]
 CPU 노트북       →      GPU 워크스테이션  →    GPU 서버 1대    →     GPU 클러스터
 1~2명 동시           10~20명 동시          50~100명 동시         500명 이상
 20~40초 응답         3~5초 응답            1~2초 응답            < 1초 응답
```

### 3.2 단계별 상세

#### 🔵 0단계 — 시연·PoC (현재)
| 항목 | 내용 |
|---|---|
| 목표 | 보안 모델 검증, 핵심 기능 시연 |
| 장비 | 데스크톱/노트북 1대 |
| 비용 | 0원 (기존 장비 활용) |
| 응답 속도 | 20–40초 |
| 동시 사용자 | 1–2명 |
| 적합 규모 | 시연, 개념 검증 |

#### 🟢 1단계 — 소규모 부서 도입 (3~6개월)
| 항목 | 내용 |
|---|---|
| 목표 | 1개 부서 (10~20명) 정식 도입 |
| 장비 | **GPU 워크스테이션 1대** (RTX 4090 / RTX 5090 / A6000) |
| 비용 | 약 **300~600만원** (1회) |
| 응답 속도 | **3–5초** (ChatGPT 수준) |
| 동시 사용자 | 10–20명 |
| 추가 효과 | 문서 색인 속도 10배 향상 (페이지당 0.5초) |
| ROI | 직원 10명 × 시간 절감 → **연 3~5천만원 절감** (1년 내 회수) |

#### 🟠 2단계 — 기관 전체 도입 (6~12개월)
| 항목 | 내용 |
|---|---|
| 목표 | 기관 전체 (50~100명) 운영 |
| 장비 | **GPU 서버 1대** (NVIDIA A100 80GB / H100 80GB) |
| 비용 | 약 **3,000~6,000만원** (1회) + 운영비 |
| 응답 속도 | **1–2초** |
| 동시 사용자 | 50–100명 |
| 추가 기능 | • 멀티모달 (이미지·도표 질의)<br>• 부서별 권한 분리<br>• 감사 로그 SIEM 연계 |
| ROI | 100명 기준 **연 3억 이상 절감** |

#### 🔴 3단계 — 대규모 운영 (1~2년)
| 항목 | 내용 |
|---|---|
| 목표 | 광역 기관 / 그룹사 통합 운영 |
| 장비 | **GPU 클러스터 (4~8대 H100)** + 고가용성 구성 |
| 비용 | 2~5억 (장비) + 연 운영비 |
| 응답 속도 | < 1초 |
| 동시 사용자 | 500명 이상 |
| 추가 기능 | • 자체 fine-tuning (도메인 특화 모델)<br>• 다국어 (영·중·일)<br>• Active-Standby HA |

## 4. 하드웨어 외 소프트웨어 개선 로드맵

장비 업그레이드와 별개로, **무상 업데이트**로 제공되는 개선 항목입니다.

### 4.1 단기 (3개월 이내) — Q3 2026

| 항목 | 효과 |
|---|---|
| **모델 양자화 (INT4/INT8)** | CPU 환경에서도 응답 시간 30~40% 단축 |
| **스트리밍 응답 강화** | 첫 토큰 출력 < 5초 (체감 속도 개선) |
| **검색 캐시 도입** | 동일 질문 반복 시 즉시 응답 |
| **HWP/HWPML 표 추출** | 법령·조례 별표 정확도 향상 |

### 4.2 중기 (6개월 이내) — Q4 2026

| 항목 | 효과 |
|---|---|
| **재순위(Reranker) 모델 적용** | 검색 정확도 87% → 92% |
| **답변 인용 정밀도 향상** | 출처 청크 → 출처 문장 단위 표시 |
| **다단계 추론 (Chain-of-Thought)** | 복합 질의(여러 문서 비교) 정확도 향상 |
| **사용자 피드백 학습** | 👍/👎 기반 검색 가중치 자동 조정 |

### 4.3 장기 (12개월 이내) — 2027

| 항목 | 효과 |
|---|---|
| **도메인 특화 fine-tuning** | 법령/금융/의료 등 분야별 정확도 +10~15% |
| **이미지 OCR 정확도 강화** | 스캔된 PDF·사진 문서 인식률 95% 이상 |
| **음성 입력/출력** | 회의 녹취 자동 요약 |
| **다국어 지원** | 영문·중문·일문 문서 통합 검색 |

## 5. 정량적 비교 — "ChatGPT는 왜 빠른가"

| 비교 축 | ChatGPT | BAIKAL (현재) | BAIKAL (1단계) |
|---|---|---|---|
| 추론 인프라 | H100 GPU **수천 장 클러스터** | CPU 1대 | RTX 4090 1장 |
| 추정 인프라 비용 | 수조원 (OpenAI 자본) | 0원 (기존 노트북) | 300만원 |
| 응답 속도 | 2–5초 | 20–40초 | 3–5초 |
| **데이터 위치** | **미국 클라우드** | **고객 내부망** | **고객 내부망** |
| 학습 데이터화 | 가능 (정책 의존) | **불가능 (물리 격리)** | **불가능** |

> **결론** — 동일한 보안 수준에서 ChatGPT 수준의 속도를 얻으려면
> **GPU 1장(약 300만원)** 추가가 필요합니다. 이는 ChatGPT가 **수조원**의
> 인프라를 동원하는 것과 비교하면 매우 합리적인 비용입니다.

## 7. 자주 묻는 질문 (성능 관련)

**Q1. 시연에서 30초 걸렸는데, 실무 도입에서도 그런가요?**
> 아니요. 시연은 **CPU 노트북(최저 사양)** 환경입니다. 도입 시 GPU 1장 추가 시
> **3~5초**로 줄어듭니다. 견적에 GPU 비용이 포함됩니다.

**Q2. GPU 없이는 못 쓰나요?**
> 사용 가능합니다. 동시 사용자 1~2명, 1일 50~100건 질의 규모라면 CPU만으로도
> 운영 가능합니다. 이 경우 응답은 20~40초가 표준입니다.

**Q3. 응답이 느린 동안 직원이 기다려야 하나요?**
> 스트리밍 출력으로 **첫 글자는 5초 이내**에 표시됩니다. 직원은 답변을 읽는
> 동안 자연스럽게 다음 작업을 준비할 수 있습니다.

**Q4. 모델을 더 작게(빠르게) 바꿀 수는 없나요?**
> 가능합니다. 3B 양자화 모델 적용 시 CPU에서도 **8~15초**까지 단축됩니다.
> 단, 정확도가 약 5~10% 하락하므로 용도에 따라 선택합니다.

**Q5. 향후 GPT-5 / Claude 4 같은 신모델로 교체 가능한가요?**
> 가능합니다. **상용 클라우드 모델은 폐쇄망 정책상 사용 불가**하지만, 동급의
> 오픈소스 모델(Llama 4, Qwen 3 등)이 출시되는 즉시 교체 가능하며,
> 이는 **무상 업데이트**로 제공됩니다.

**Q6. 정확도(검색·답변)는 얼마나 보장되나요?**
> 자체 평가 결과 **Top-5 Recall 87%**, 답변 정확도 약 80%대 후반 수준이며,
> Reranker 도입(2026 Q4)으로 92%까지 향상 예정입니다. 또한 신뢰도 임계값
> 미달 시 **자동으로 답변을 거절**하여 할루시네이션을 차단합니다.
