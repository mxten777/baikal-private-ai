# BAIKAL Private AI — 완성도 분석 및 상용화 개선 과제

> 분석 기준일: 2026-04-03

---

## 전체 평가: 기능 완성도 70%, 상용화 준비도 30%

핵심 RAG 파이프라인(업로드→청킹→임베딩→검색→LLM 스트리밍)은 실제로 작동하는 완성된 구현체입니다.
하지만 보안 취약점과 기능 버그가 실제 배포를 막고 있습니다.

---

## 🔴 즉시 수정 필수 (보안 치명적)

| # | 문제 | 위치 |
|---|------|------|
| 1 | **CORS 와일드카드 + credentials=True 동시 설정** — 브라우저 스펙상 무효, 크로스 오리진 인증 파괴 | `backend/app/main.py` |
| 2 | **하드코딩된 JWT 시크릿 키** — `.env` 없이 배포 시 알려진 키로 토큰 위조 가능 | `backend/app/config.py` |

| 5 | **문서 다운로드 소유권 검사 없음** — 모든 인증된 사용자가 타인의 문서 ID로 다운로드 가능 | `backend/app/api/documents.py` |

## 🟠 프로덕션 배포 전 수정 (운영 안정성)

| # | 문제 |
|---|------|
| 9 | **단일 uvicorn 워커** — LLM 요청 하나가 모든 API 블로킹. `gunicorn -w 4` 또는 `--workers 4` 필요 |
| 10 | **Alembic 마이그레이션 디렉토리 없음** — `alembic`이 requirements에 있으나 실제 마이그레이션 부재. DB 스키마 변경 시 수동 DROP TABLE 하거나 데이터 손실 위험 |
| 11 | **백그라운드 문서처리 중 서버 재시작 시 복구 불가** — 처리 중 상태로 영구 고착. 감시 작업(watchdog) 없음 |
| 12 | **HTTPS 없음** — nginx가 80포트 HTTP만 처리 |
| 13 | **비밀번호 최소 길이 4자** — 상용 기준에 턱없이 부족 |

## 🟡 단기 개선 필요 (품질/보완)

| # | 문제 |
|---|------|
| 14 | **JWT 토큰 `localStorage` 저장** — XSS 공격 시 토큰 탈취 가능. `HttpOnly` 쿠키 권장 |
| 15 | **SSE 스트리밍이 Axios 인터셉터 우회** — 토큰 만료 시 스트리밍 중 갱신 불가, 그냥 실패 |
| 16 | **BM25 IDF가 상수** — `math.log(2)` 고정값 사용으로 단어 희귀도 미반영. "하이브리드 검색" 실제 효과 절반 |
| 17 | **목록 API 페이지네이션 없음** — 문서/사용자/세션 목록 대규모 데이터 시 전 건 반환 |
| 18 | **`.gitignore` 없음** — `frontend/build/`(빌드 산출물), 실제 업로드 파일(`.hwpx`), `.env`가 git에 커밋될 위험 |
| 19 | **실제 사용자 파일이 이미 git에 커밋됨** — `backend/backend/uploads/1fe673a7...hwpx` |
| 20 | **CHUNK_SIZE 설정 불일치** — `config.py` 기본값 800자, `.env.example`은 500자 |
| 21 | **Nginx 보안 헤더 없음** — `X-Frame-Options`, `Content-Security-Policy`, `X-Content-Type-Options` 누락 |
