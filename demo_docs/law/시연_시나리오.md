## 5분 시연 (제안 미팅 첫 데모)

### 0:00 – 0:30 | 오프닝
> *"지금부터 5분 동안 ChatGPT로는 불가능하고, 외부 클라우드도 사용하지 않는 행정 법령 검색을 보여드리겠습니다. 먼저 표준 데모셋 5건으로 시연하고, 곧이어 귀 기관의 자체 자료를 직접 올려보실 수 있습니다."*

- 화면에 BAIKAL 첫 화면 + 상단 disclaimer 배너 노출
- 좌측 문서 목록에 5건의 표준 자료 표시 (HWP 원본 그대로)

### 0:30 – 2:00 | 핵심 검색 (질문 #1)
**질문 입력**: *"정보공개 청구의 처리 기간은 며칠인가요? 연장은 가능한가요?"*

확인할 포인트:
- ✅ 답변에 **굵은 글씨**로 일수 강조 ("10일, 부득이한 경우 10일 연장")
- ✅ "📄 출처: 공공기관의 정보공개에 관한 법률 제○조" 명시
- ✅ 신뢰도 배지 (예: "신뢰도 78%")
- ✅ 출처 칩 클릭 시 원문 청크 미리보기

> *"보시는 것처럼 조항 번호와 원문이 그대로 노출됩니다. 환각이 아니라 실제 법령에서 인용한 결과입니다."*

### 2:00 – 3:00 | 거절 시나리오 (질문 #16)
**질문 입력**: *"다음 분기 예산은 얼마인가요?"*

확인할 포인트:
- ✅ 빨간색 **"답변 거절 · low_confidence"** 배지
- ✅ "관련도가 낮아 답변을 생성하지 않습니다" 메시지

> *"법령 도메인에서 가장 위험한 것은 AI가 모르는 것을 아는 척 답하는 것입니다. BAIKAL은 자체적으로 신뢰도를 측정해서, 임계 미만이면 LLM 호출 자체를 차단합니다."*

### 3:00 – 4:30 | 다중 문서 비교 (질문 #13)
**질문 입력**: *"정보공개법과 표준 정보공개 조례안의 처리 기간 규정을 표로 비교해 주세요"*

확인할 포인트:
- ✅ 표 형식 출력
- ✅ 두 출처 분리 표기 (상위법 vs 표준조례안)
- ✅ 같은 질문을 ChatGPT에 던졌을 때 HWP 업로드 자체가 안 된다는 점 언급

### 4:30 – 5:00 | 클로징 + 자료 호환성 강조
- 분석 문서 §7-2의 4줄 비교표 한 슬라이드로 마무리

| 항목 | ChatGPT | BAIKAL |
|------|:------:|:------:|
| HWP 원본 업로드 | ❌ | ✅ |
| 인터넷 차단 환경 | ❌ | ✅ |
| 출처(조항/페이지) 표시 | ❌ | ✅ |
| 데이터 외부 전송 | ❌ 전송 | ✅ 없음 |

> *"오늘은 표준 5건이지만 동일한 정확도로 귀 기관의 자체 조례·내부 지침 HWP를 검색할 수 있습니다. PoC 단계에서 직접 확인해 보시기를 권합니다."*

## 15분 풀버전 (PoC 입회 평가)

### Phase 1 (0–4분): 표준 데모셋 시연
- 위 5분 시연 그대로

### Phase 2 (4–7분): 정량 평가 — `eval_rag.py` 화면 공유
```powershell
python scripts/eval_rag.py --testset scripts/eval_testset.json --output md
```

산출 결과 화면:
- Precision@5 / Recall@5 / MRR / nDCG@5 / Reranking Lift
- 자동 생성된 [docs/TEST_RESULTS.md](../../docs/TEST_RESULTS.md) 표

> *"수치가 있다는 것 자체가 다른 RAG 솔루션과 차별점입니다."*

### Phase 3 (7–10분): 보안 자가점검 — `security_audit.py`
```powershell
python scripts/security_audit.py --output audit_report.md
```

체크리스트:
- SECRET_KEY 강도 ✅
- 관리자 비밀번호 변경 ✅
- 외부 도메인 호출 0건 ✅
- 의존성 CVE 스캔 결과

### Phase 4 (10–13분): **고객사 자료 즉석 색인 (핵심 차별화)**

> *"이제 귀 기관의 자료로 직접 해 보겠습니다. HWP 1~2건만 주시면 5분 내로 색인됩니다."*

- 고객 USB → BAIKAL 업로드 페이지로 직접 끌어오기
- 처리 완료 후 고객이 직접 질문
- [질문지_20개.md](질문지_20개.md) D그룹 형식의 거절 시나리오를 일부러 입력해보도록 유도 — 이게 핵심 차별화

### Phase 5 (13–15분): 클로징 + 다음 단계
- *"오늘 본 내용은 USB 한 개로 폐쇄망에 그대로 설치 가능합니다."*
- `scripts/export-images.ps1` 산출물 화면 캡처 노출

## 주의 사항

- ❗ **시연 중 환각 답변 발견 시**: 당황하지 말고 *"이런 경우 신뢰도 임계를 0.50까지 올리면 차단됩니다"* 라고 설정 가능성을 강조 (`MIN_CONFIDENCE_THRESHOLD` 환경변수)
- ❗ **인터넷 끊긴 환경에서도 동일하게 동작**한다는 사실을 시연 도중 1회 이상 언급
- ❗ **HWP 미지원 경쟁 솔루션**과의 비교는 구체적 제품명 대신 "외산 솔루션" 으로 표현 (법적 분쟁 방지)
- ❗ **표준조례안은 모델조항이지 실제 시행 조례가 아님** — 시연 중 "이건 행안부 표준안이고, 귀 기관 실제 조례는 일부 다를 수 있습니다" 라고 미리 짚어두기 (정확성 의심 사전 차단)
