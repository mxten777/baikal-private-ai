## 1. 표준 5건 구성 (지자체 미지정 범용)

> 어느 기관 앞에서도 "당신네 일과 관련 있는 문서" 로 보이도록 **국가법령 + 표준조례 + 공통지침** 을 혼합한다.

| # | 분류 | 문서명 | 출처 사이트 | 형식 | 비고 |
|---|------|--------|-------------|------|------|
| 1 | 국가법령 | **공공기관의 정보공개에 관한 법률** | 국가법령정보센터 (`law.go.kr`) | HWP | 정보공개 처리기간·비공개사유 — 시민·내부 모두 관심 |
| 2 | 국가법령 | **행정절차법** | 국가법령정보센터 | HWP | 처분·송달·청문 절차 — 모든 행정기관 공통 |
| 3 | 표준조례 | **표준 정보공개 조례안** (행정안전부) | 자치법규시스템 (`elis.go.kr`) | HWP | 모든 지자체가 참고하는 원본 |
| 4 | 표준조례 | **표준 공무원 복무 조례안** (행정안전부) | 자치법규시스템 | HWP | 휴가/근무시간 — 일반 공무원 일상 검색 |
| 5 | 공통지침 | **국가공무원 복무·징계 관련 예규** (인사혁신처) 또는 **공공기관 운영 지침** | `mpm.go.kr`, 정부24 | HWP/PDF | 인사 분야 공통 지침 |

> **선정 기준**:
> - 모두 **공공저작물 자유이용허락 (KOGL Type-1)** 또는 **공공정보 공개 대상** → 저작권 제약 없음
> - **HWP 원본** 제공 비율이 높아 BAIKAL의 HWP 강점이 그대로 작동
> - 시연 청중이 본인 업무와 즉시 연결할 수 있는 보편 주제

### 1-1. 다운로드 방법

#### ① 국가법령정보센터 (#1, #2)

```
1. https://www.law.go.kr 접속
2. 검색창에 법령명 입력 → "현행법령" 결과 선택
3. 우측 상단 "다운로드" 버튼 → "한글파일(.hwp)" 선택
4. demo_docs/law/documents/ 에 저장
```

> 검색이 안 되면 "공공기관의 정보공개에 관한 법률" 정확 명칭으로 검색.

#### ② 자치법규정보시스템 ELIS (#3, #4)

```
1. https://www.elis.go.kr 접속
2. "표준 자치법규" 메뉴 → "표준조례안" 검색
3. 해당 표준안 클릭 → "원문 다운로드 (HWP)"
4. demo_docs/law/documents/ 에 저장
```

> 표준조례안이 주기적으로 갱신될 수 있으므로 가장 최신 버전을 사용.

#### ③ 정부 사이트 (#5)

```
1. 인사혁신처: https://www.mpm.go.kr → "정책정보" → "예규/지침"
2. 또는 정부24: https://www.gov.kr → 공공기관 자료실
3. HWP 우선, 없으면 PDF 다운로드
```

### 1-2. 업로드

```
1. BAIKAL 관리자 계정 로그인
2. 좌측 "문서" → "업로드"
3. demo_docs/law/documents/ 5개 파일 일괄 선택 → 업로드
4. 처리 완료 대기 (~ 2~3분, CPU 환경 기준)
```

## 2. 시연 5분 — 핵심 질문 3개

| 단계 | 질문 | 강조 포인트 |
|------|------|-------------|
| 1️⃣ | "정보공개 청구 시 처리 기간은 며칠인가요?" | 국가법령(#1) 출처 명시 — "10일, 부득이한 경우 10일 연장" |
| 2️⃣ | "행정처분 통지 송달 방법은 무엇이 있나요?" | 행정절차법(#2) — 송달 방법 다중 항목 |
| 3️⃣ | "다음 분기 예산은 얼마인가요?" | **답변 거절** (Confidence Gate 시연) |

> 거절 응답은 **버그가 아닌 핵심 데모**다. "AI가 모르는 건 모른다고 답하는 시스템" 이 법령 도메인의 가치.

## 3. 범용 데모의 세일즈 메시지

시연 도중 다음 한 문장을 1회 이상 노출한다:

> *"오늘 시연한 5건은 표준 데모셋입니다. 귀 기관의 자체 조례와 내부 지침 HWP 파일을 그대로 올리시면 동일한 정확도로 검색됩니다. PoC 단계에서 직접 시도해 보시기를 권합니다."*

### 분석 문서 §3-3 "첫 고객 부재" 대응

- 범용 5건이라 어느 기관에든 들고 갈 수 있음 → 콜드 미팅 진입 장벽 ↓
- 시연 후 즉시 "그럼 우리 자료로 한번 해볼까요?" 라는 다음 질문을 유도
- PoC = 고객사 자체 문서 색인이 자연스러운 다음 단계
